# docs

Setup notes for this project — accounts to create, API keys to obtain,
domain/DNS setup for Cloudflare Pages, and any other one-time setup steps
that don't belong inside a specific folder's own README.

- [`deploy.md`](./deploy.md) — deploying `kiosk/` to Cloudflare Pages
  (two ways: Git auto-deploy or direct upload with Wrangler), the
  `_headers` security headers file, and updating the backend's
  `ALLOWED_ORIGIN` afterward.
- [`kiosk-setup.md`](./kiosk-setup.md) — setting up the physical kiosk
  device: Windows mini PC, portrait TV, USB webcam, Chrome kiosk mode,
  auto-start/crash-recovery, and a daily staff checklist.
